What is the "PHP-to-Shell" Risk?

Historically and in modern misconfigured environments, poorly isolated PHP web applications can expose attack surfaces where unvalidated inputs allow direct execution of arbitrary commands in the operating system shell.

php2shell-check automates preventive scanning, checking target behavior, evaluated PHP versions, and exposure risks.

Operation Modes

Web Mode 🌐 Active

Performs custom HTTP/HTTPS requests against remote targets to inspect response headers, PHP-exposed headers, WAF detection, and SSL validation.

-m web

Local Mode 💻 CLI

Inspects the local PHP environment running via CLI to verify php.ini security configurations and installed versions.

-m local

Quick Installation & Usage

git clone https://github.com/Pauloxc6/php2shell-check.git
cd php2shell-check
bash php2shell-check.sh --help
